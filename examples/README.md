# PRD Assistant Examples

This directory contains example outputs generated by the PRD Assistant tool to demonstrate its capabilities.

## Example Project: Real-time Chat Messaging System

The `example-project/` directory contains a complete example of:

1. **PRD Document**: `example-project_Real-time_chat_messaging_system_with_file_sharing_and_emoji_reactions.md`
   - Comprehensive Product Requirements Document
   - Includes overview, goals, user stories, functional requirements, success metrics, and technical considerations
   - Generated using AI with the Gemma3n model

2. **Technical Tasks**: `tasks_example-project_Real-time_chat_messaging_system_with_file_sharing_and_emoji_reactions.md`
   - Detailed technical implementation tasks
   - Organized by feature areas with specific subtasks
   - Includes file structure, testing requirements, and deployment considerations

## How to Generate Your Own Examples

### 1. Initialize a Project
```bash
prd-assistant init-project your-project-name
```

### 2. Generate a PRD
```bash
cd your-project-name
prd-assistant generate-prd your-project-name "Your feature description"
```

### 3. Generate Technical Tasks
```bash
prd-assistant generate-tasks your-project-name "Your feature description"
```

### 4. Audit a PRD
```bash
prd-assistant audit-prd your-project-name "Your feature description"
```

## Features Demonstrated

- **AI-Powered Content Generation**: Uses Ollama with Gemma3n model
- **Comprehensive PRD Structure**: Professional-grade product requirements documents
- **Technical Task Breakdown**: Detailed implementation roadmaps
- **File Management**: Automatic filename sanitization and organization
- **Project Context**: Maintains project-specific configuration and templates

## File Naming Convention

- PRD files: `{project-name}_{feature-name}.md`
- Task files: `tasks_{project-name}_{feature-name}.md`
- Special characters are automatically sanitized for filesystem compatibility

## Requirements

- Rust 1.70+
- Ollama with Gemma3n model running locally
- Internet connection for AI model access

For more information, see the main project documentation.
