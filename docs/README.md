## 🔧 Key Features

### Core Functionality

- **Project Management**: Initialize and manage PRD projects with templates and rules
- **AI-Powered Generation**: Generate comprehensive PRDs using Ollama with Gemma3n
- **Intelligent Auditing**: Audit existing PRDs with customizable rules and criteria
- **Template System**: Flexible template system with default and technical templates
- **Custom Rules**: Customizable audit and generation rules for specialized needs

### Technical Highlights

- **Rust-Powered**: Built with Rust for performance and reliability
- **Async/Await**: Full async support with Tokio runtime
- **AI Integration**: Seamless integration with local AI models via Ollama
- **Cross-Platform**: Works on Linux, macOS, and Windows
- **Extensible**: Modular architecture for easy extension and customization
